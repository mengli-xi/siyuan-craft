# 智能目录 (Smart Folder)

专为思源笔记（SiYuan `3.8+`）打造的轻量目录增强插件，解决「多层分类文件夹全部是空白文档页、点击目录容易误开空白标签页、纯目录与有正文的父文档难以区分」三大痛点。

## 核心功能

1. **统一目录点击交互**
   - **单击目录标题**：无论是否为 0 字纯目录，所有包含子文档的目录节点均 0ms 即时展开 / 折叠子文档。
   - **进入目录本身**：支持 **双击标题** 或 **按住 `Option / Alt` 单击** 打开该目录文档页。

2. **文件夹视觉区分**
   - 在文档树中自动为 **0 字纯目录** 渲染醒目的实心文件夹图标（随展开/收起状态动态切换开合图标）。
   - 为 **含正文的父级文档** 渲染「文档目录」专属图标，一眼区分点击预期；用户手动设置的自定义 Emoji 图标完全保留不覆盖。

3. **无侵入式目录概览卡片**
   - 当通过双击或面包屑打开 0 字纯目录页时，自动在视图层渲染子目录与子笔记卡片列表（支持目录内实时筛选跳转）。
   - **零数据污染**：纯前端视图层挂载，绝不改动底层 `.sy` 文档数据；右上角提供 **「✎ 编写正文」** 按钮，随时可切回编辑器撰写总览内容。
